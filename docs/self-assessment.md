# Conformance self-assessment

Against the [trsdn Repository Quality Standard](https://github.com/trsdn/.github) v1.3.3, assessed
2026-08-28. The machine-readable result is [`.github/conformance.yml`](../.github/conformance.yml);
the badge in the README is rendered from it and cannot be edited independently.

**Result: Healthy — 47 pass, 0 partial, 0 fail, 37 not applicable.**

This is a Swift package. It has no application, no user interface, no installer, no deployment and
no user data, so a large share of the standard genuinely does not apply. Those are recorded as
`na` rather than quietly passed.

## What is not applicable, and why

- **Deployable (D01–D06)** — nothing is deployed. The package is compiled into someone else's
  binary; it has no runtime, no environment and no rollback of its own. Consumers pin it by
  version, and that pin is their rollback.
- **Product identity (I01–I06)** — there is no product surface: no application, no icon, no
  installer, no store listing, no site.
- **Accessibility (X01–X05)** — no user interface.
- **Documentation repositories (T01–T05)** — this is not a documentation repository.
- **Data protection (Y01, Y03–Y06)** — the package reads a file and returns bytes. It collects
  nothing, stores nothing, and reaches no network, so there is no data to classify, export, retain
  or delete. Y02 does apply and passes: the README serves its badges from this repository rather
  than a third-party image host, so no external service observes readers.
- **Localization (L03–L06)** — the package emits no user-facing strings. Its errors are typed Swift
  values that a consumer presents.
- **S06** — there is no configuration. The one tunable, `maximumEntrySize`, is a constructor
  argument with a documented default.
- **Archived (A01–A04)** — actively developed.

## Notes

Two defects were found while preparing this repository, both fixed rather than recorded as gaps:

- The uncompressed-size ceiling — the only defence against a decompression bomb in code reached by
  selecting a downloaded file in Finder — had no test at all. It has four now.
- The README documented a method and a fallback case that do not exist. `READMEExampleTests`
  compiles the documented example, so that cannot recur silently.
